# Markdown 进阶笔记
## 一、Markdown 的底层原理
Markdown 是一种**轻量级标记语言**，它本质是纯文本，通过简单标记符号，约定文本的排版含义。
编辑器（VS Code）或者网站（GitHub）里有渲染器，会把这些标记翻译成 HTML，最后展示成带格式的页面。
- 源文件：`.md` 纯文本，任何编辑器都能打开
- 渲染器：读取符号，转换成富文本效果
- 特点：源码易读、不绑定某一个软件

## 二、VS Code 编辑器实用小功能
1. 预览 Markdown：快捷键 `Ctrl + Shift + V`，打开预览窗口，一边写一边看效果
2. 自动补全：输入语法时，插件可以提示表格、链接、代码块模板
3. 分屏：一边编辑源码，一边看预览
4. 批量替换：`Ctrl + H`，统一修改文字、链接
5. 文件夹管理：直接在资源管理器新建、重命名 `.md` 文件，配合 Git 使用

## 三、Markdown 的局限
Markdown 擅长：笔记、README、文档、简单清单、技术记录
Markdown 不擅长：
1. 复杂图文排版：复杂多栏布局、精美海报、花哨版式
2. 复杂公式：虽然支持LaTeX公式，但写起来繁琐，大量数理推导不方便
3. 复杂绘图：流程图、思维导图、架构图原生支持弱
4. 精细样式控制：很难自定义字体颜色、大小、边距
5. 交互式文档：动画、表单、弹窗等交互内容做不了

## 四、适合弥补这些短板的软件
- 思维导图：XMind、MindMaster
- 复杂公式、数理笔记：Typora（增强Md）、Obsidian（插件）、Overleaf（LaTeX）
- 流程图、架构图：Draw.io（Diagrams.net）
- 精美图文排版：WPS、Word、Canva可画
- 知识库双向链接：Obsidian

## 五、总结
Markdown 主打简洁、通用、适合代码和技术文档；如果需要复杂排版、绘图、大量公式，可以搭配别的工具，再把生成的图片插入 Markdown 里。
