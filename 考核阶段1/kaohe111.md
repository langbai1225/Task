## GitHub 是干什么的？ Pull Request、Fork 这些词你是怎么理解的，又是从哪里学到的？
1. GitHub是基于Git的代码托管平台，用来存代码、多人协作开发，是程序员的线上仓库。
2. Pull Request（PR）即拉取请求，是代码协作机制。开发者完成代码修改后，发起PR，请求项目负责人审核并将改动合并到主分支，支持代码评审、讨论，保障多人协作开发规范。
3. Fork 是将他人的仓库复制一份到自己账号下，生成独立副本，方便在不改动原项目的前提下修改代码，之后可以通过PR提交改动给原项目。
4. 学习渠道：我通过豆包、B站、抖音上的技术教程了解这些概念，同时也会自己动手理解整个协作流程。
## 有学长当年光是打开 GitHub 网站就花了半天，你有过类似经历吗？ 不管有没有，说说你的判断。
- 我有过类似经历,我一开始还以为GitHub是一个应用,让后我就在浏览器打开官网去下载,然后发现下载很慢,我就去网上搜为什么下载那么慢,后面我才知道GitHub 的服务器在境外，国内没有部署服务器，浏览器下载文件要走跨境国际线路，距离远、链路容易拥堵、丢包，所以速度经常只有几十KB/s.要下载加速器才能加速下载.我又下载了一个加速器,才把软件下载下来.后面我才知道用网页就行了.
