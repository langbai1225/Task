# 学习过程中遇到的困难:
1. 刚开始学习Markdown语法时，容易混淆各类标记符号，图片插入、链接写法经常出错，预览效果和自己预想不一致。

- [x] 解决方案: 整理一份Markdown常用语法速查表，写文档的时候对照使用，多写多预览，慢慢熟悉格式规则
2. GitHub操作逻辑比较抽象，分不清网页端上传、VS Code Git推送两种方式，曾经出现过上传文件为空、提交失败、路径写错导致图片加载不出来的问题。
- [x] 解决方案: 优先使用VS Code本地写文件，再用git命令推送，减少网页拖拽上传带来的空文件问题；写完一条就测试图片、链接能否正常显示。
