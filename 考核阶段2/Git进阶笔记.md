# 如果提交错了怎么办？——了解一下版本回滚和冲突解决。这会让你收获很多！
---
1. 提交出错的处理方案（版本回滚）
场景：提交内容写错、传错文件，想要撤销这次提交。
- 先查看所有历史提交记录，拿到要回退到的那个版本的commit编号
命令：
git log
---


2. 两种回滚方式
 
-  git reset --soft 目标commit-id （推荐，安全）
只撤销这条提交记录，你写的内容还留在本地，可以修改后重新提交，不会丢失文字。
​
-  git reset --hard 目标commit-id （谨慎使用）
撤销提交，并且直接删掉本次所有改动，内容很难找回，一般不推荐新手用。
---
3. 冲突解决
产生场景：多人协作时，两个人修改了同一个文件的同一处内容，Git无法自动判断保留哪一份，就产生冲突。
