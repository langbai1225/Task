3. **问题：初次使用 Git 提交代码报错，提示未配置用户名、邮箱**
- 问题原因：刚安装的 Git 是空环境，没有绑定个人提交身份，系统不知道是谁提交的代码。
- 解决方法：在 Git Bash 中输入两条全局配置命令，一次配置永久生效。
git config --global user.name "你的用户名"
git config --global user.email "你的邮箱"
配置完成后，所有本地提交都会带上自己的身份信息，不再报错。
---
4. **问题：VS Code 识别不到 Git，无法使用图形化提交、同步功能**
- 问题原因：安装 Git 时没有勾选添加到系统环境变量，导致 VS Code 找不到 Git 程序。
- 解决方法：重新安装或修复 Git，允许加入系统环境变量，之后关闭 VS Code 并重启，即可正常识别。

5. **问题：GitHub 网页加载慢、图片打不开、克隆速度极慢**
问题原因：GitHub 服务器在境外，国内网络不稳定。
解决方法：使用国内加速镜像链接、切换网络、或错开高峰时间段操作，大幅提升访问与克隆速度。
